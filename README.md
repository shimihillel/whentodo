# מתי עשיתי את זה?!

אפליקציית GitHub Pages מקומית ופשוטה למעקב אחר פעולות חוזרות.

## גרסה מעודכנת: רענון עיצוב ואייקון

סגול רך, כרטיסים בהירים, צבעי קטגוריות עדינים ואייקון שעון עם וי.
כולל התאמה למובייל, סימון מיקוד למקלדת ותמיכה בהפחתת תנועה.

### עדכון האתר הקיים

החליפי את קבצי האתר הקיים בכל הקבצים שב-ZIP, כולל `style.css`
ו-`icon.svg`, והשאירי את כתובת האתר כפי שהיא. הנתונים נשמרים בדפדפן
לפי כתובת האתר. שם מסד הנתונים ומבנה הגיבוי נשארו תואמים לגרסה הקודמת.
לפני העדכון אפשר לשמור עותק דרך תפריט גיבוי.

לאחר הפרסום, סגרי ופתחי את האפליקציה ורענני כדי לטעון את העיצוב החדש.
אייקון שכבר נוסף למסך הבית עשוי להתעדכן רק לאחר הוספת קיצור הדרך מחדש.

## העלאה ל-GitHub Pages
1. פתחי Repository חדש.
2. העלי את כל הקבצים שבתיקייה הזו לשורש ה-Repository.
3. היכנסי ל-Settings → Pages.
4. בחרי Deploy from a branch, את main ואת /(root).
5. שמרי.

הנתונים נשמרים מקומית בדפדפן באמצעות IndexedDB. מומלץ לבצע גיבוי מהתפריט מדי פעם.
